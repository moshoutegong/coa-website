# COA 中文资料站

**同一个职业的同一个技能，从天赋树到技能图鉴，再到游戏里，尽量使用同一个中文名字。**

本站是面向 Conquest of Azeroth（COA）玩家的中文资料站，核心是**全职业天赋模拟器**和**双语技能图鉴**。目前收录 **21 个职业、70 个专精、3,616 条天赋数据和 4,637 条技能图鉴数据**。

[进入首页](index.html) · [天赋模拟器](talents.html) · [双语技能图鉴](spells.html) · [全站搜索](search.html)

## 为什么要统一汉化

同一个职业的技能，有时在技能书里是一种译名，在天赋描述里又是另一种。玩家读到「强化某技能」或「触发某效果」时，得先反查英文，才能确认说的是不是自己已经学会的那个技能。遇到多等级、替换技能或触发效果时，这个问题尤其明显。

本站把译名和机制一起核对。整理时以客户端数据为依据，用法术 ID 和等级链确认同一技能，核对天赋描述里引用的技能和触发效果，再统一职业页面、天赋说明与技能图鉴中的叫法。不同法术即使英文同名，也不会仅凭名称合并。翻译时保留原有的触发条件、作用对象、数值和持续时间；来源有疑问的地方保留待核对标记。

**这套统一后的汉化已全部提供在黑猫助手中。** 网页上查到的译名和术语，可以在游戏里接着用。需要在客户端使用这套汉化，可从[网站首页的黑猫助手区](index.html)进入下载入口。

## 核心功能

### [全职业天赋模拟器](talents.html)

- 选择职业和专精，分别规划职业天赋与专精天赋。
- 支持加点、退点、重置，以及前置天赋、点数门槛和二选一节点的判断。
- 悬停天赋可查看说明；多级天赋可查看不同等级的效果。
- 加点方案保存在当前浏览器中，方便下次打开继续调整。

### [双语技能图鉴](spells.html)

- 按职业浏览技能，中英文对照，便于核对游戏内说明和英文攻略。
- 支持按中文名、英文名或法术 ID [搜索](search.html)，并查看已收录的技能等级与关联效果。
- 数据有提供时，可查看资源消耗、射程、施法时间、冷却和充能等参数。图鉴与天赋模拟器沿用同一套译名，便于从天赋描述查到对应技能。

## 本地预览与部署

在仓库根目录运行以下命令，再打开 [http://localhost:8000/](http://localhost:8000/)：

```sh
python -m http.server 8000
```

部署时保留目录结构，将网页、`assets/`、`classes/` 和 `data/` 一起上传到静态托管。入口为 `index.html`，无需构建或数据库。线上建议使用 HTTPS，方便使用浏览器剪贴板功能。

天赋方案、个人宏和 WA 存在当前浏览器中，换浏览器、设备或域名后不会自动迁移。

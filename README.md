# COA 中文资料站

面向 COA 玩家整理的中文静态资料站。包含职业与专精介绍、天赋模拟器、双语技能图鉴、构筑参考、宏与 WeakAuras 工具，以及世界铸造物品位置查询。

## 浏览与部署

- 本地浏览：从仓库根目录启动静态服务器，例如 `python -m http.server 8000`，再打开 `http://localhost:8000/`。
- 部署：将仓库中的网站文件按原目录结构上传到静态托管，入口为 `index.html`。无需构建或数据库。线上建议使用 HTTPS，以便使用剪贴板功能。
- 天赋、个人宏和 WA 数据保存在当前浏览器中，不会自动跨设备或域名同步。

本站仅保留与 COA 相关的地图功能。无限版本的独立世界地图和配套 3D 参考入口已移除；世界铸造中的物品位置地图仍可使用。

本站为非官方玩家资料站。社区构筑和评级仅供参考，请以对应服务器及客户端的实际表现为准。游戏素材归原权利人所有。
